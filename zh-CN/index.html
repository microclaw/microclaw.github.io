RUST 智能体运行时

一套 Rust Agent Engine：直接运行，也可以嵌入。

一套可嵌入的 Rust 智能体内核，同时驱动 Server、原生 Work 和你的应用。

把 MicroClaw 用作常驻 Server、原生本地 Work，或者自己 Rust 产品里的 SDK；三条路径共享工具、记忆、Skills、安全策略和执行生命周期。

Server + Work可嵌入 SDKSQLite 持久化
01集成开发

Rust SDK

适合 Rust 产品与平台团队

把完整 Agent Engine，或仅稳定的执行生命周期契约，嵌入自己的应用。

  • Agent、Skills、事件与控制
  • 本地与认证远程 Worker
  • 不依赖 Server、渠道或桌面 UI
加入 Cargo.toml
microclaw-sdk = { version = "0.5", features = ["full"] }
开始集成 →
02最快上手

MicroClaw Work

适合围绕本地项目开展工作

安装原生桌面应用，几分钟内开始理解工作空间的智能体对话。

  • 原生 GPUI 桌面体验
  • 项目上下文、审批与检查点
  • Skills 与可观测 Subagent
安装到 Apple Silicon macOS
brew tap microclaw/tap && brew install --cask microclaw-work
使用 MicroClaw Work →
03持续在线

MicroClaw Server

适合服务、聊天渠道与自动化

运行持久化智能体服务，承载聊天渠道、Web 与 Agent API、调度和后台任务。

  • 支持 macOS、Linux 与 Windows
  • Web 控制台与多渠道适配器
  • 调度、恢复与可靠投递
安装 ServermacOS
curl -fsSL https://microclaw.org/install.sh | bash
部署 Server →

为什么团队选择 MicroClaw

以运行时为中心，让渠道、模型和工具变化时核心逻辑依然稳定。

可嵌入 Rust SDK

Server、Work 与第三方应用通过稳定 Run 契约使用同一套 Agent Engine。

原生桌面 Work

Rust/GPUI 工作空间投影共享运行时事件，不内置 Web UI。

工具型 Agent Loop

模型可以跨多个步骤连续调用工具，直到任务完成。

有界 Subagent

Main Agent 可以把任务交给可观测、可取消的原生或 ACP Worker。

带质量门槛的记忆

文件和 SQLite 记忆具备提取、去重和生命周期控制。

技能 + MCP

内置技能和外部 MCP Server 无需修改核心循环即可扩展能力。

运维可见性

用量、记忆观测、配置检查、指标和链路追踪让漂移可见。

调度与后台任务

周期任务和一次性任务都复用同一运行时。

一套 Engine，三种使用方式

Server、Work 与第三方 Rust 应用都通过 SDK 汇入同一套 provider 无关 Agent Engine 和 Runtime。

01

选择入口

Server 接收渠道、Web、API 和协议请求；Work 接收原生任务；Rust 应用使用 microclaw-sdk。

02

进入共享 Engine

所有入口调用同一套 Agent Loop、provider、Skills、工具、安全策略和记忆。

03

投影运行时事件

Server 负责渠道投递；Work 和第三方应用消费同一套有序事件。

04

持久化与恢复

会话、检查点、审批、记忆和任务状态保持一致语义。

05

准确的平台边界

Server 支持 macOS、Linux 和 Windows；Work 正式支持 macOS，并发布 Linux 和 Windows portable 预览包。
